# غِراس 🌱

**قصصٌ تُروى، وقيمٌ تُغرس**

أداة ويب بسيطة تولّد قصة أطفال عربية مخصصة بأسلوب إسلامي، مع صورة واحدة لأهم مشهد في القصة.

**🌐 الموقع المباشر:** [ghiras.kids](https://ghiras.kids)

## التقنيات

- Next.js (App Router) + TypeScript
- Tailwind CSS
- OpenAI لتوليد النص والصورة
- Zod للتحقق من المدخلات والمخرجات
- خط «ثمانية» محليًا عبر `next/font/local`

بدون تسجيل دخول، وبدون قاعدة بيانات — لا يتم حفظ أي بيانات.

## التشغيل

1. ثبّت الحزم:

   ```bash
   npm install
   ```

2. انسخ ملف البيئة وأضف مفتاح OpenAI:

   ```bash
   cp .env.example .env.local
   # ثم ضع مفتاحك في OPENAI_API_KEY
   ```

3. شغّل الخادم:

   ```bash
   npm run dev
   ```

4. افتح المتصفح على [http://localhost:3000](http://localhost:3000)

## متغيرات البيئة

| المتغير | الوصف |
| --- | --- |
| `OPENAI_API_KEY` | مفتاح OpenAI (مطلوب) |
| `OPENAI_TEXT_MODEL` | نموذج النص (اختياري، الافتراضي `gpt-4o-mini`) |
| `OPENAI_IMAGE_MODEL` | نموذج الصورة (اختياري، الافتراضي `gpt-image-1`) |
| `MOYASAR_SECRET_KEY` | المفتاح السري لبوابة الدفع «ميسر» (اختياري — بدونه يظهر الدفع كـ«قريبًا») |
| `MOYASAR_WEBHOOK_SECRET` | الرمز السري للتحقق من إشعارات ميسر |
| `NEXT_PUBLIC_SITE_URL` | عنوان الموقع لبناء رابط العودة بعد الدفع (اختياري) |

## الدفع الإلكتروني (ميسر)

الخدمات المدفوعة في `/khadamat` تُدفع عبر [ميسر](https://moyasar.com) بطريقة
Invoices API: يُنشئ الخادم فاتورة ثم يُحوّل المشتري إلى صفحة دفع مستضافة عند
ميسر، فلا تمرّ بيانات البطاقة على غِراس إطلاقًا.

**المسارات:**

| المسار | الوظيفة |
| --- | --- |
| `POST /api/checkout` | إنشاء الفاتورة وإرجاع رابط الدفع |
| `/api/moyasar/callback` | عودة المشتري بعد الدفع (يقبل GET و POST) |
| `POST /api/moyasar/webhook` | إشعار ميسر — المصدر الموثوق لتأكيد الطلب |
| `/checkout/result` | عرض نتيجة الدفع بعد التحقق من الخادم |

**التفعيل:**

1. من لوحة ميسر ← «مفاتيح الربط» انسخي المفتاح السري التجريبي `sk_test_...`
   واضبطيه في `MOYASAR_SECRET_KEY`.
2. من لوحة ميسر ← «الإشعارات» أضيفي رابطًا إلى `/api/moyasar/webhook` لحدثَي
   `payment_paid` و `payment_failed`، وضعي الرمز السري في `MOYASAR_WEBHOOK_SECRET`.
3. جرّبي عملية شراء كاملة ببطاقة الاختبار، ثم تحقّقي من ظهورها في اللوحة.
4. بعد نجاح التجربة استبدلي المفتاح بـ `sk_live_...`.

> السعر لا يُرسل من المتصفح أبدًا؛ يُقرأ في الخادم من `PRODUCTS` في
> `lib/services.ts`، ويُعاد التحقق من المبلغ والعملة بعد الدفع قبل تأكيد الطلب.
>
> **التسليم حاليًا يدوي:** بيانات كل طلب (البريد، اسم الطفل، التفاصيل) تُرفق في
> `metadata` وتظهر في لوحة ميسر. التسليم الآلي وإرسال البريد نقطة واحدة في
> `handlePaidPayment` داخل `lib/orders.ts`.

> ملاحظة: نموذج `gpt-image-1` قد يتطلب توثيق المؤسسة في حساب OpenAI. إن لم يكن متاحًا لديك، اضبط `OPENAI_IMAGE_MODEL=dall-e-3`.
